# AI Model Comparison: Landing Page Generation

## 1. AI Models Used
* **Model 1:** ChatGPT (GPT-5.6 Luna)
* **Model 2:** Grok (Fast)

## 2. Prompt Used
> "Create a beautiful, lucrative, and responsive .html landing page for an FDE (Forward Deployed Engineer) Service."

## 3. Code Quality Observation
A comparison of the code generated by both models:

| Area | ChatGPT | Grok |
| :--- | :--- | :--- |
| **Code Structure** | Scripts and CSS are self-contained within the HTML file. | Same |
| **Readability** | CSS and scripts are well-organized. | CSS, scripts, and other sections are placed correctly. |
| **Component Design** | Created a carousel design with multiple sections along with a modal feature. | Same, but created more sections. |
| **Documentation** | Only CSS sections have comments. | All section blocks have comments. |
| **Error Handling** | The modal has form validation. | Same |

## 4. AI Hallucination Observation
* The AI did not ask me for the company name; instead, it chose one randomly.
* The AI built unnecessary features to add complexity.

## 5. Final Decision
Based on my observations, both models produced good results. However, Grok provided a more complex structure with a dark theme and also used external dependencies, while GPT used fewer sections to keep it simple and relied on no external dependencies. Both maintained structured code with a responsive design.

**Overall, ChatGPT wins!**
