# Todo API

## Commands
- Install: `npm install`
- Run dev server: `npm run dev`
- Test: `npm test`
- Lint: `npm run lint`

## Code style
- TypeScript, strict mode
- Use async/await, never callbacks
- Every new endpoint needs a test in `tests/`

## Rules
- Never edit files in `src/generated/`
- Never commit `.env`
- Keep PRs small: one feature per change
